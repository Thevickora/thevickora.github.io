## 📝 Как обновить контент

### Изменить имя и описание:
Открой `index.html`, найди секцию `<header class="hero">` и измени:
- `<h1>` — твоё имя
- `<p class="hero-subtitle">` — подзаголовок
- `<p class="hero-description">` — описание

### Изменить названия проектов:
Найди `<h2 class="work-title">` и измени на свои названия

### Изменить описания проектов:
Найди `<p class="work-description">` и опиши каждую работу

### Изменить теги:
Найди `<span class="tag">` и поменяй на свои (например: Midjourney, Runway, GPT-4)

### Изменить контакты:
Найди секцию `<footer>` и измени ссылки:
- `https://t.me/yourusername` → твой телеграм
- `your@email.com` → твоя почта
- `https://profi.ru/profile/yourprofile` → твой профиль
